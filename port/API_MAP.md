### Trace rule

1. `Direct3DCreate8` returns `IDirect3D8` in EAX.
2. A store of that pointer types its destination: global, stack slot, or struct field keyed by
   the base object's identity plus displacement.
3. `CreateDevice` through the vtable at 0x3C types its 7th argument as `IDirect3DDevice8`.
4. A typed load carries the type; `mov reg,[iface]` is the vtable, `lea` carries the slot.
5. A candidate is every `call dword ptr [reg+disp]` whose displacement is a method offset.

Limits: EAX/ECX/EDX are clobbered at every call and branch; only the ten copy mnemonics
(MOV, MOVQ, MOVD, MOVSS, MOVLPS, MOVHPS, MOVLPD, MOVUPS, MOVAPS, MOVDQA) type a memory
destination; every other write clears the identity key; a stack slot type survives a merge only
when every predecessor agrees; the loop fails loudly at 50 passes.

Unresolved reason classes: `unproven-base` 5215, `unknown-memory` 360, `argument` 103,
`computed` 11, `indirect-function-pointer` 1, `unsupported-operand` 1.

### Render loop entry

The function that calls Present is not resolved in either tier. Present-shaped sites (0x3C)
start at 0x4211F8 in `FUN_00420fb0`, then 0x44AD81 in `FUN_0044ad60` and 0x44C122 in
`FUN_0044c050`, all unresolved `unknown-memory`.

```
4211b6: mov ecx, [0x9fee08]       ; renderer singleton
4211bc: mov edx, [ecx]            ; its vtable
4211be: call dword ptr [edx+0x1c] ; accessor returns the device
4211c1: mov ecx, [eax]            ; device vtable
4211c8: call dword ptr [ecx+0xc8] ; SetRenderState(0xF, 0)
```

The accessor's target is `mov eax,[0x6d09b8]; mov eax,[eax+0xec]; ret` (0x53a0b0), so no
static store types the device. `FUN_00420fb0` has no direct callers because it is invoked
virtually. A 0x3C call on a thiscall object with no pushed arguments (0x506F71) is an engine
method, not Present.
