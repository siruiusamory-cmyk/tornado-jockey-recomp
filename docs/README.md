## Measurement record

`port/` holds evidence, not the pitch. Every claim carries a tag: MEASURED, RUNTIME-PROVEN,
INFERRED, UNVERIFIED or BLOCKED.

| File | Contents |
| :--- | :--- |
| [`port/GAME.md`](../port/GAME.md) | intake: installer, PE, imports, recovered image, simulation facts |
| [`port/API_MAP.md`](../port/API_MAP.md) | D3D8, DInput8 and FMOD call sites with address and caller |
| [`port/D3D8_CALL_SITES.md`](../port/D3D8_CALL_SITES.md) | generated by `tools/d3d8_census.py`; do not edit |
| [`port/D3D8_USAGE.md`](../port/D3D8_USAGE.md) | argument sets the game passes, decoded per method |
| [`port/STATUS.md`](../port/STATUS.md) | per-stage record: measurement, result, open items |
| [`port/RENDERER.md`](../port/RENDERER.md) | the renderer abstraction, legacy backend and D3D12 backend |
| [`port/REPLAY.md`](../port/REPLAY.md) | replay format, virtual clock, opt-in switches |
| [`port/STATE_CENSUS.md`](../port/STATE_CENSUS.md) | object classes and fields, snapshot/restore proof |
| [`port/SAVE_FORMAT.md`](../port/SAVE_FORMAT.md) | save file v1 |
| [`port/VISION.md`](../port/VISION.md) | long-range design plan |
| [`port/TIERS-REVIEW.md`](../port/TIERS-REVIEW.md) | per-item verdict against that plan |

Untracked by design: the game directory, the intake copy, the evidence directory and the build
directory. None is distributed.

## Maintenance

A stage freeze rewrites `port/STATUS.md` in the same commit as the stage's code;
`docs/STATUS.md` points at it and keeps no counts. `docs/ROADMAP.md` changes when a register
row moves. `port/D3D8_CALL_SITES.md` is generated; regenerate rather than edit.
